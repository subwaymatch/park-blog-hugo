# Repository guidelines

## Writing style

This applies to every piece of text written for this repository: posts,
templates, code comments, commit messages, pull request titles and
descriptions, and replies in chat.

- Use plain ASCII punctuation. Never use em dashes, en dashes, curly quotes,
  the single-character ellipsis, arrows, or other typographic characters that
  are common in AI-generated text. Rewrite the sentence, use a plain hyphen or
  colon, use straight quotes, and write "..." if an ellipsis is needed.
- Decorative characters that belong to the site's design (the arrows, dots and
  connectors in the theme templates, emoji in posts) are the author's choice
  and stay as they are.
